# История изменений

В этом файле описаны изменения, важные для пользователей. Версии следуют формату `MAJOR.MINOR.PATCH`.

## [0.1.0] - 2026-10-19

Первый релиз.

### Добавлено

- Локальный MCP-сервер по stdio для Jira Server и Data Center. Требуется Node.js 24 или новее.
- Вход по логину и паролю через команду `bluntjira login`. Пароль не сохраняется; данные сессии хранятся в `~/.bluntjira/settings.json` с правами доступа только для владельца.
- Чтение проектов, задач, комментариев и доступных переходов статусов; поиск задач через JQL с пагинацией.
- Создание задач, обновление полей, добавление комментариев и выполнение переходов статусов от имени пользователя Jira.
- Ограниченные повторные попытки для запросов чтения при HTTP 429, 502, 503 и 504. Операции записи автоматически не повторяются.
- Пятиминутная пауза запросов после HTTP 401 или 403, таймауты запросов и скрытие реквизитов в сообщениях об ошибках.

### Ограничения

- Jira Cloud и вход только через браузерный SSO не поддерживаются.
- После истечения сессии необходимо повторно выполнить вход.
- Если результат операции записи неизвестен из-за ошибки, перед повтором нужно проверить Jira: изменение могло успеть выполниться.

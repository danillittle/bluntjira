GET STARTED

Три шага. И ты в деле.

Нужны Node.js 24+ и AI-клиент с поддержкой локальных MCP-серверов.

  1. 01

    Войди в Jira

    Выполни команду и введи HTTPS-адрес Jira, логин и пароль. Если нужен VPN — подключи его заранее.

    ТЕРМИНАЛ

    npx -y bluntjira@0.2.0 login
  2. 02

    Подключи MCP-сервер

    Добавь конфигурацию в настройки MCP своего AI-приложения. Затем перезапусти приложение или переподключи сервер.

    Подробнее о настройке ↗

    НАСТРОЙКИ MCP · JSON

    {
  "mcpServers": {
    "bluntjira": {
      "command": "npx",
      "args": ["-y", "bluntjira@0.2.0"]
    }
  }
}
  3. 03

    Просто спроси

    Начни с доступных проектов или своих задач. Помощник сам подберёт нужный инструмент.

    ↳

    «Покажи мои незакрытые задачи»

Перед подключением. Логин и пароль хранятся открытым текстом в ~/.bluntjira/settings.json (права 600). Не передавай этот файл другим и не добавляй его в Git. Помощник может менять реальные задачи — включи подтверждение действий в AI-клиенте.

ПЕРЕД СТАРТОМ

Коротко о важном.

Работает с Jira Cloud?+

Нет. Поддерживаются Jira Server и Data Center с входом по логину и паролю. Вход только через браузерный SSO также не поддерживается.

Куда отправляются данные?+

bluntjira работает локально и обращается к твоему серверу Jira. Результаты передаются AI-клиенту и могут обрабатываться его провайдером модели. Проверь политику своего приложения и правила компании.

Что делать, если запрос завершился ошибкой?+

Перед повторным созданием задачи или отправкой комментария проверь Jira: действие могло успеть выполниться. Остальные решения — в документации.

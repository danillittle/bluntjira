ПОДКЛЮЧЕНИЕ

Три шага — и Jira в чате.

Без клонирования репозитория и сборки. npx загрузит пакет и запустит сервер на твоём компьютере.

  1. Подготовь окружение

    Установи Node.js 24 или новее с npm. Понадобится AI-приложение с поддержкой локальных MCP-серверов (stdio).

    Поддерживаются Jira Server и Data Center с входом по логину и паролю. Если Jira в корпоративной сети, сначала подключись к ней или включи VPN. Jira Cloud и вход только через SSO не поддерживаются.

  2. Войди в Jira

    Открой терминал и выполни команду. Отдельно устанавливать bluntjira не нужно.

    ТЕРМИНАЛ
    npx -y bluntjira@0.1.0 login

    Введи полный HTTPS-адрес Jira, например https://jira.example.com, затем логин и пароль. При вводе пароля символы не отображаются. Пароль не сохраняется.

  3. Подключи AI-приложение

    Открой настройки MCP своего клиента и добавь сервер. Расположение настроек зависит от приложения.

    КОНФИГУРАЦИЯ MCP · JSON
    {
  "mcpServers": {
    "bluntjira": {
      "command": "npx",
      "args": ["-y", "bluntjira@0.1.0"]
    }
  }
}

    Если клиент предлагает отдельные поля, укажи npx в команде, а -y и bluntjira@0.1.0 — в аргументах.

    Перезапусти приложение или переподключи сервер. Затем напиши в чате: «Покажи доступные проекты Jira».

Помощник действует с твоими правами Jira и может изменять реальные задачи. Включи подтверждение действий в AI-приложении, если оно это поддерживает. Данные сессии хранятся в ~/.bluntjira/settings.json — не передавай этот файл другим.

bluntjira подключает Jira к AI-приложению через MCP. После подключения можно просить помощника найти задачу, прочитать обсуждение, создать новую задачу или перевести её в другой статус. Доступ к проектам и задачам остаётся таким же, как у твоей учётной записи Jira.

## Подключение

Понадобятся [Node.js 24 или новее](https://nodejs.org/) с npm и AI-приложение, которое поддерживает локальные MCP-серверы (stdio).

Поддерживаются Jira Server и Data Center с входом по логину и паролю. Jira Cloud и вход через браузерный SSO не поддерживаются. Если Jira доступна только в корпоративной сети, сначала подключись к ней или включи VPN.

### 1. Войди в Jira

Открой терминал и выполни:

```bash
npx -y bluntjira@0.1.0 login
```

Введи адрес Jira, логин и пароль. Используй полный HTTPS-адрес, например `https://jira.example.com` или `https://jira.example.com/jira`. При вводе пароля символы не отображаются.

Пароль не сохраняется. Данные сессии останутся на компьютере, чтобы не входить заново при каждом запуске.

### 2. Добавь сервер в AI-приложение

Открой настройки MCP в своём приложении и добавь:

```json
{
  "mcpServers": {
    "bluntjira": {
      "command": "npx",
      "args": ["-y", "bluntjira@0.1.0"]
    }
  }
}
```

Расположение настроек зависит от приложения. Если оно предлагает отдельные поля вместо JSON, укажи `npx` в поле команды, а `-y` и `bluntjira@0.1.0` в аргументах.

Перезапусти приложение или переподключи сервер в настройках MCP.

### 3. Попробуй в чате

- «Покажи доступные проекты Jira».
- «Найди мои незакрытые задачи».
- «Покажи описание и комментарии к PROJ-123».
- «Создай задачу в проекте PROJ: исправить ошибку входа».
- «Добавь к PROJ-123 комментарий: исправление готово к проверке».
- «Какие статусы доступны для PROJ-123?»

Замени `PROJ` и `PROJ-123` на свой проект и задачу. Для создания задачи помощник может запросить её тип и другие обязательные поля.

## Что важно знать

Помощник может изменять реальные задачи от твоего имени. Включи подтверждение действий в настройках AI-приложения, если оно это поддерживает. Если создание задачи или отправка комментария завершились ошибкой, проверь Jira перед повтором: действие могло успеть выполниться.

Данные сессии хранятся в `~/.bluntjira/settings.json` и дают доступ к Jira. Не передавай этот файл другим и не добавляй его в Git.

## Если не работает

| Проблема | Что сделать |
|---|---|
| Команда `npx` не найдена | Установи Node.js 24+ с npm и перезапусти терминал и AI-приложение |
| Не удаётся войти | Проверь адрес, логин, пароль и подключение к корпоративной сети. При CAPTCHA сначала войди в Jira через браузер. Вход только через SSO не поддерживается |
| Сессия истекла | Снова выполни `npx -y bluntjira@0.1.0 login`, затем переподключи сервер в AI-приложении |
| Нет доступа к проекту или задаче | Проверь, доступны ли они твоей учётной записи в самой Jira |
| После ошибки доступа запросы приостановлены | Проверь вход, права и CAPTCHA. Пауза длится пять минут |

Если проблема остаётся, создай [issue](https://github.com/danillittle/bluntjira/issues). Укажи версию Node.js, AI-приложение и текст ошибки. Не прикладывай пароль или данные сессии.

## Для разработчиков

### Установка из Git

```bash
git clone https://github.com/danillittle/bluntjira.git
cd bluntjira
npm ci
npm run build
node dist/index.js login
```

Для подключения локальной сборки используй команду `node` с аргументом `/absolute/path/to/bluntjira/dist/index.js`, указав свой абсолютный путь.
